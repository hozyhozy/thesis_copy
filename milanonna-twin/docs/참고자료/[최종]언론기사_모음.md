# [최종] 언론 기사 모음 (밀라논나 본인 발언 중심 요약)

- 성격: 기사 본문은 기자의 글이므로 그대로 옮기지 않음. 기사당 밀라논나 직접 인용 1개만 원문, 나머지는 요약(paraphrase).
- 용도: 말투 학습용이 아니라 배경 지식(페르소나 사실) 보강용. QA의 `voice` 필드로 구분.
- 제외: 뉴시스 2024-09 복귀 기사(복귀 인터뷰 영상과 중복), 머니투데이·스포츠경향·국악타임즈 2025-05(서장훈의 이웃집 백만장자 방송과 중복), 라디오스타 관련 기사 3건·한국경제 수상 기사(직접 인용 없음), 조선일보·조선비즈·한겨레·매일경제(접근 차단), 네이트(robots 차단), 인스타그램·나무위키(1차 자료 아님), 유튜브 링크 4건(자막 파일 필요).

- 요약: 뉴발란스와 협업 영상을 만든 배경을 다룬 기사. 밀라논나는 편하면서도 스타일리시하게 매치할 수 있는 운동화를 고르는 기준을 소개하고, 브랜드의 역사와 창업자의 철학을 알고 제품을 사면 더 믿음이 가고 의미가 있다고 말함.
- 직접 인용: "어떤 브랜드인지 역사를 제대로 알고 신으면 더 신뢰가 가지 않겠냐"

## [기사] 경향신문 플랫 — 1952년생 '밀라노 할머니'가 보여준 멋지게 나이드는 법
- 매체: 언론기사·경향신문 플랫(칼럼) / 날짜: 2021-01-06
- URL: https://www.khan.co.kr/article/202101061000001
- 요약: 밀라논나 영상 속 발언을 모아 '잘 늙는 법'을 조명한 칼럼. 젊은 시절로 돌아가고 싶냐는 물음에 단호히 아니라고 답하며 한 번 젊어 봤으면 됐다고 말하고, 50대는 해방이었고 60대인 지금이 가장 좋다고 함. 소장품이 대부분 오래됐다는 말에는 자신이 낡은 사람이니 물건도 낡은 게 당연하다고 받아넘김. 머리숱이 적다는 것도 숨기지 않고 말함.
- 직접 인용: "어우 한번 했으면 됐지. 어떻게 안 늙어. 나도 한번 젊어봤잖아."

## [기사] 이코노미조선 — 수입은 기부, 시신은 기증, 어른 대접은 사양합니다
- 매체: 언론기사·이코노미조선(김지수 기자) / 날짜: 2021-09-12
- URL: https://economychosun.com/site/data/html_dir/2021/09/12/2021091200005.html
- 요약: 첫 에세이 출간 즈음의 인터뷰 기사. 유튜브 수입은 기부하고, 사후에는 시신을 기증하며, 어른 대접은 사양한다는 태도를 제목으로 뽑음. 8세 어린이부터 83세 노인까지 폭넓은 구독층에 본인이 더 놀랐다고 하고, 삶의 진짜 가치는 자기 시간을 누군가에게 내어주는 것이라고 말함.
- 직접 인용: "삶의 진짜 가치는 내 시간을 누군가에게 내어주는 것"
