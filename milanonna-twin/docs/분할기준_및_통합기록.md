## 1. 분할 기준 (2026-11-09 개정: 시간 기준 + 내용 겹침 제거)

**최종 규칙 (`split`)**
1. 시간 기준으로 1차 분할: 복귀(2024-08, 시즌 2) 이후 발화 = Holdout 후보, 그 이전 = Train. (`split_time`에 보존)
2. Holdout 후보 각 문항을 Train 내용과 대조해 재배정 (`reassign.py`):
   - **같은 질문**이 Train에 있으면 → `Retest` (Train도 Holdout도 아님. 본인이 같은 질문에 시즌 1·2에서 얼마나 같게 답했는지 = human ceiling 계산 전용)
   - 답에 Train에 이미 있는 **인생 일화**(삼풍, 86 아시안게임, 78년 유학, 돌체 동기, 명품 유치, 염색 중단, 큰아들 수술, 유튜브 시작, 수익 기부 등 24개 패턴)가 들어 있으면 → `Train`으로 이동 (학습 재료로 활용)
   - 둘 다 아니면 → `Holdout` (Train이 모르는 질문·내용만 남음)
3. 결과: 시간상 Holdout 후보 306 → novel 264 / shared_anecdote 28 / same_question 14. 각 문항의 판정은 `overlap`, `overlap_detail` 필드.

이렇게 하면 "Holdout에는 Train이 이미 답을 알고 있는 내용이 없다"가 태그가 아니라 분할 설계로 보장됨. 엄격 기준(`split_strict`, 2025년 이후)은 그대로 보존되어 Holdout 안의 부분집합으로 강건성 검사에 사용.

<details><summary>이전 설계(2026-11-08, 2단 Holdout) 기록</summary>


**주 기준 `split`: 복귀(2024년 8월, 시즌 2) 이후 발화 = Holdout, 그 이전 = Train.**
**엄격 기준 `split_strict`: 2025-01-01 이후 = Holdout.** (엄격 Holdout ⊂ 주 Holdout)

- 주 기준의 근거: 복귀는 임의의 날짜가 아니라 본인 활동의 자연스러운 단절점(2022.7~2024.8 공백). "시즌 1 발화로 트윈을 만들어 시즌 2 발화를 예측한다"는 설계. Holdout 306문항으로 검정력과 하위 분석(일화 회상형/가치관형, interview/derived) 확보.
- 엄격 기준의 용도: 누수(memorization) 반박용 강건성 검사. 주 분석 결과가 2025년 이후 155문항에서도 같은 패턴이면 "모델이 외운 것"이라는 해석을 배제할 수 있음.
- 누수 통제의 핵심은 날짜가 아니라 G0 베이스라인(페르소나 없이 '밀라논나라면'만 묻는 조건). G0가 Holdout에서 높으면 모델이 이미 알고 있다는 뜻이며, 트윈의 기여는 '트윈 − G0'로만 주장.
- 채널 공백기 덕분에 2024년 자료는 전부 복귀 후 자료이므로, 시기가 '2024(추정)'로만 잡힌 영상도 주 기준에서 Holdout.
- 폴더(Train/, Holdout/)는 주 기준으로 나뉨. 엄격 기준은 JSON의 `split_strict` 필드와 분할표의 `split_strict` 열로 필터.
- 앞으로 추가하는 2024-08 이후 채널 영상은 모두 Holdout 후보.

검토했으나 채택하지 않은 기준
- 2025-01-01 단일 기준(이전 버전): 누수 방어는 강하나 Holdout 155로 검정력 부족 → 엄격 기준으로 격하.
- 채널 분할(자기 채널=Train, 외부 인터뷰=Holdout): 질문 형식은 깔끔하지만 시간 누수를 못 막음.
- 질문 유형 분할(derived=Train, interview=Holdout): 같은 영상이 양쪽에 걸려 누수가 큼.

시기 판정 방법
- 업로드일이 파일명·제목에 있으면 그대로 사용(확인).
- 외부 방송은 방송일 검색으로 확인(유퀴즈 2020, 대화의 희열 2021-07-15, 사사건건 2025-06-20, 이웃집 백만장자 2025).
- 나머지는 단서로 추정: 제목의 `[eng]` 접두어(초기 활동기 형식), 첫 책(2021.8)/두 번째 책(2024.8) 홍보 발언, 영상 속 "결혼 47년", "94년에 산 옷이 27년 됐다" 등.
- 씬메이커·토크콘서트(약 2021), 더페이스(약 2023)는 사용자가 유튜브 표시('5년 전', '3년 전')로 확인 → Train 확정. 날짜를 고칠 때는 `merge_split.py`의 DATES를 수정하고 재실행하면 분할표·통합 파일이 다시 생성됨. "2024~(추정)" 자기 채널 영상 5편도 2025년 이후로 확인되면 Holdout으로 이동해야 함.

## 2. 통합 및 중복 처리

- 665문항을 한 파일로 합침. `id` = `영상ID_q###`.
- 질문+답이 완전히 같은 항목: 0개(클립 영상 `9_tNDJQefbo`는 원본과 중복이라 QA를 뽑지 않았음).
- 같은 질문을 여러 영상에서 따로 답한 경우 8묶음 → 삭제하지 않고 `dup_group`으로 묶음. 같은 질문에 대한 본인의 반복 답변은 사람 자신의 test-retest 일관성(human ceiling) 추정에 쓸 수 있는 자료이기 때문.
  - G01 밀라논나 뜻(2) · G02 유튜브 시작 계기(6) · G03 롤모델이라는 말(2) · G04 부모님과의 이별 준비(2) · G05 인생이란(2) · G06 용기와 두려움(2) · G07 흰머리 염색 중단(2) · G08 하고 싶은 것이 있을 때(2)
  - 반복 질문의 Holdout 쪽 문항은 모두 `Retest`로 빠졌으므로 Train/Holdout 간 같은 질문 누수는 없음. 평가 시 해당 Holdout 문항은 제외하거나 따로 표시할 것.
- 같은 일화(삼풍, 86 아시안게임, 염색 중단 등)가 여러 영상에 반복되므로 Train의 일화가 Holdout 답에도 나올 수 있음. 이는 실제 인물의 일관성이지 데이터 오류는 아니나, "트윈이 일화를 외웠다"는 해석과 구분하려면 평가 항목을 '일화 회상형'과 '의견·가치관형'으로 나눠 보고하는 것을 권장.
